# Информационная система управления заказами такси
## Калиничев Вячеслав
## Общее описание

Данный проект реализует комплексную систему управления заказами такси, построенную на принципах объектно-ориентированного программирования. Система имитирует работу реального сервиса такси с поддержкой различных классов автомобилей, гибкой системой тарифов и динамическим ценообразованием.

## Архитектура системы

### 1. Модуль персонажей (Person.kt)
**Абстрактный класс Person** определяет общие характеристики для всех участников системы. От него наследуются:
- **Client** - представляет клиента такси с информацией о способе оплаты
- **Driver** - описывает водителя с рейтингом и привязанным транспортным средством, включает кастомный геттер для проверки доступности

### 2. Модуль транспортных средств (Vehicle.kt)
**Абстрактный класс Vehicle** содержит общие свойства всех автомобилей. Иерархия наследования включает:
- **EconomyCar** - базовый класс эконом-такси
- **ComfortCar** - автомобили комфорт-класса с кондиционером
- **BusinessCar** - премиальный класс с дополнительными услугами, переопределяет проверку доступности
- **Minivan** - автомобили повышенной вместимости

### 3. Модуль тарифной системы (Tariffs.kt)
**Абстрактный класс Tariff** определяет общую структуру тарифов. Ключевой компонент - **DynamicPricingEngine**, реализующий систему динамического ценообразования. Тарифы-наследники:
- **EconomyTariff** - базовый расчет стоимости
- **ComfortTariff** - повышенные ставки за улучшенный сервис
- **BusinessTariff** - включает фиксированную плату за премиум-услуги
- **MinivanTariff** - учитывает количество пассажиров

### 4. Модуль управления заказами (Order.kt)
**Sealed class OrderStatus** ограничивает возможные состояния заказа:
- Поиск водителя → Назначен водитель → Поездка начата → Завершена/Отменена

**Data class Route** хранит информацию о маршруте с кастомным геттером для форматированного отображения.

**Класс Order** управляет полным жизненным циклом заказа, используя композицию для связи с маршрутом и ассоциации с другими объектами системы.

## Формирование стоимости поездки

### Многоуровневая система расчета:

**1. Базовый тариф**
Каждый класс автомобиля имеет фиксированные ставки:
- Эконом: 10 руб/км + 5 руб/мин
- Комфорт: 15 руб/км + 7 руб/мин
- Бизнес: 25 руб/км + 10 руб/мин + 100 руб сервисный сбор
- Минивэн: 20 руб/км + 8 руб/мин

**2. Динамическое ценообразование (Surge Pricing)**
Система автоматически применяет коэффициенты в зависимости от уровня спроса:
- Низкий спрос (<20%): коэффициент 0.9 (скидка 10%)
- Нормальный спрос (20-40%): коэффициент 1.0 (базовая цена)
- Средний спрос (40-60%): коэффициент 1.2 (надбавка 20%)
- Высокий спрос (60-80%): коэффициент 1.5 (надбавка 50%)
- Очень высокий спрос (>80%): коэффициент 1.8 (надбавка 80%)

**3. Итоговая формула расчета**
Стоимость = (Расстояние × ЦенаЗаКм + Время × ЦенаЗаМинуту) × КоэффициентСпроса + ДополнительныеУслуги

Проект удовлетворяет всем необходимым требованиям, демонстрируя полноценную объектно-ориентированную архитектуру с реалистичной бизнес-логикой системы такси, включая сложные механизмы расчета стоимости и управления состоянием заказов.
